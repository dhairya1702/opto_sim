# Krimsky in the shared Practice clinic

## Scope and acceptance

Add standard and modified Krimsky to the existing library's Quest/WebXR entry. Reuse `PracticeVRClinic`, the canonical patient, penlight/prism models, ownership/input runtime, headset panels and accessible browser mirror. Keep desktop Krimsky unchanged. Do not add another room, physical runtime, Test case or scoring path. Work stays on `vr-improvements`; servers, commits, push and deployment remain off.

The learner identifies and picks up the penlight/prism, instructs fixation, acknowledges monocular examiner viewing, obtains a baseline without a prism in front of an eye, and places the gold-ringed working cell before the appropriate eye. Existing authored endpoints remain 20Δ BI and 15Δ BO with OD fixating/OS deviating: standard prism before OS, modified before OD. The real penlight working point and headset view supply distance/aim/view checks; real prism pose supplies eye/tilt/placement. Base and integer power settings alter the existing illustrative relative-reflex model continuously, including wrong-base divergence and overcorrection. No case answer or endpoint is preselected/disclosed by UI labels.

## Implementation sequence

1. Add pure XR conversion/technique, patient-scale relative-reflex, explicit completed-comparison capture and submission functions. Reuse `krimskyReady`, `krimskyResidual`, `krimskyEye` and the Hirschberg spatial technique adapter; retain the existing 46–54 cm teaching zone. Reuse existing prism placement tolerances rather than invent a second handling system.
2. Extend the shared lesson form with optional numeric fields: blank labeled HTML number input and in-headset ±1/±5/clear controls. Keep existing choice forms and their layout unchanged. Numeric entry is the learner's independent reading; do not fill it from the selected prism power.
3. Add a Krimsky adapter with standard/modified selection, fixation, monocular-view acknowledgement, explicit baseline inspection, BI/BO and 0–40Δ settings in 1Δ steps (15Δ must be reachable), live relative reflexes, comparison capture, recording, help, reset, next finding and exit. Use refs for live frame state and rate-limit React readouts.
4. Solve two-hand recording explicitly: the prism-hand trigger compares the reflexes while the light/placement/view are valid. Only a matching comparison creates an immutable completed observation containing the selected method/eye/base/power and actual illustrative distance. The learner can then release the light, place instruments down or use A/X and enter the observed power. The form opens only on request; capture does not itself grant completion.
5. Preserve completed capture across subsequent physical handling so two-hand entry is usable. Before capture, light/distance/aim/view/tracking invalidation clears baseline/pending entry; generic pickup/menu interrupts clear pending entry. Changing method, base, power or finding clears capture; reset recalls tools and clears all state. Cancelled entry records nothing and clears capture, requiring a fresh comparison. Session exit clears capture/input; late calls cannot award completion. A correct explicit numeric submission awards local Practice completion once per attempt.
6. Add pure math checks and mounted two-controller walkthroughs for both methods and both authored endpoints, baseline order, wrong tool/eye/base/tilt, under/overcorrection, parameter/tracking interruption, release-to-record, blank/wrong numeric entry, cancellation, duplicate completion, reset/new finding and exit. Run focused affected tests, TypeScript/Vite build and whitespace checks only; no Playwright or full suite.
7. Synchronize learner workflow, clinical assumptions/review status, architecture, asset provenance and repository map. Document device limitations; do not imply Quest 3S validation.

## Limits requiring review

Monocular viewing is acknowledged, not detected; no eye tracking is requested. Reflex displacement is a patient-scale conversion of the existing simplified relative model, not calibrated prism optics. Modified Krimsky preserves visible reflexes and does not simulate a scarred cornea. A completed capture is an explicit comparison, not a timed clinical measurement or certification. Controller ergonomics, readability and clinical teaching fidelity remain draft pending qualified and physical-device review.
